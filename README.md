## Лабораторная работа №1 — фильтр Гаусса

Реализованы три варианта фильтрации: библиотечный `cv2.GaussianBlur`, прямая двумерная свёртка на Python и сепарабельная свёртка двумя одномерными проходами. Поддерживаются изображения в градациях серого и цветные изображения, независимые размеры ядра и параметры σ по горизонтали и вертикали, а также автоматический выбор σ.

Сравнение с OpenCV подтвердило корректность нативной реализации: для проверенных изображений максимальная абсолютная разность составила 1 уровень яркости, а для ядра 5×5 с автоматически выбранной σ результаты совпали побитово. Небольшие расхождения в остальных случаях связаны с различиями в численной арифметике.

По замерам на изображении 512×512 с ядром 5×5 OpenCV затратил 0,044 мс, прямая реализация Python — 737,7 мс, сепарабельная — 398,7 мс. При размере ядра 31×31 сепарабельная реализация была примерно в 11,8 раза быстрее прямой. Эксперименты также показали, что сила сглаживания зависит от согласования размера ядра с σ: слишком маленькое окно обрезает гауссиану, а чрезмерно большое увеличивает вычисления без заметного улучшения результата.

## Лабораторная работа №2 — трекинг объекта

Трекер сопоставляет ключевые точки текущего кадра с точками кадра-эталона, отбрасывает неоднозначные пары ratio-тестом Лоу, оценивает гомографию с помощью RANSAC и переносит углы объекта в кадр. Геометрические проверки препятствуют появлению рамки при случайных совпадениях. Реализованы и сравнены детекторы SIFT, ORB, AKAZE и BRISK.

В тестах с известной разметкой SIFT показал 100 % полноту на простом видео и видео с сильной перспективой; медианная ошибка углов составила соответственно 0,15 и 0,32 пикселя. На сложном видео с перекрытием, смазом и выходом объекта из кадра полнота составила 92,3 %, ложных срабатываний не было. ORB обрабатывал тесты быстрее SIFT (до 18,7 против примерно 8 кадров/с), но в сцене с сильной перспективой давал менее точную рамку. Таким образом, SIFT подходит, когда приоритетна точность, а ORB — когда важнее скорость.

Дополнительные прогоны разных режимов трекинга на видео и при размытии приведены в [сводной таблице метрик](LW2/results/metrics_test_videos.md). Например, режим `hybrid30` с SIFT обнаружил объект на всех кадрах видео `mona-lisa` со скоростью 18,6 кадра/с. Полные таблицы, графики и примеры результатов доступны в [отчете по работе №2](LW2/README.md).
